# iso/

Put **your own** dump of The Getaway (NTSC-U, SCUS-97133) here, for example
`iso/The Getaway.iso`. The image must be a plain `.iso` (2048-byte sectors).

Everything in this folder except this README is ignored by git, including
`iso/extracted/`, where `tools/scripts/extract-disc.ps1` writes the boot ELF
and IRX modules. Never commit, upload or share anything from this folder.
